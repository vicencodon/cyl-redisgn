# cyl-redisgn
# Rediseño frontend de CYL Complementos

## Descripción del proyecto

Este proyecto tiene como objetivo realizar un rediseño del frontend de la web de CYL Complementos.

La intención principal es mejorar la experiencia visual y de navegación de la página actual, simplificando menús, reduciendo redundancias en la estructura y mejorando la forma en la que el usuario encuentra productos mediante filtros más claros y útiles.

En esta primera fase nos centraremos únicamente en el rediseño visual y estructural del frontend, sin abordar todavía cambios en base de datos, dominio, backend o despliegue definitivo.

---

## Objetivos

- Modernizar la apariencia de la web
- Simplificar la navegación principal
- Reducir la cantidad de submenús innecesarios
- Mejorar la organización de categorías y productos
- Diseñar filtros más útiles e intuitivos
- Crear una base de frontend clara, mantenible y escalable
- Preparar una propuesta visual para enseñarla al propietario

---

## Alcance de esta primera fase

En esta fase se trabajará en:

- Rediseño de la página de inicio
- Rediseño del menú principal y navegación
- Rediseño de páginas de categorías
- Rediseño de fichas de producto
- Mejora visual del catálogo
- Mejora de filtros y estructura de navegación
- Adaptación responsive para móvil y escritorio

No se incluirá todavía:

- Migración de base de datos
- Cambio de dominio
- Desarrollo de backend nuevo
- Integración final con una tienda real
- Despliegue definitivo a producción

---

## Tecnologías previstas

Para esta primera fase se plantea trabajar con:

- React
- Vite
- Tailwind CSS
- GitHub

Los datos podrán simularse inicialmente con archivos locales o estructuras mock para acelerar el prototipo.
